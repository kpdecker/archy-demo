# Reference

This directory holds the **information-oriented** documentation for this repository, one of the four
kinds of documentation in [Diátaxis](https://diataxis.fr), the framework these docs follow. This
page explains what belongs here; the facts themselves live in the other files in this directory.

Reference describes the machinery accurately and completely, including APIs, configuration options,
commands, and schemas. Readers consult it instead of reading it start to finish, so keep it dry,
factual, and structured. Tutorials and opinions belong elsewhere.

See https://diataxis.fr/reference/.
