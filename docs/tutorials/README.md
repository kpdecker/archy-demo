# Tutorials

This directory holds the **learning-oriented** documentation for this repository, one of the four
kinds of documentation in [Diátaxis](https://diataxis.fr), the framework these docs follow. This
page explains what belongs here rather than teaching anything itself, and the directory starts out
empty.

A tutorial is a guided, start-to-finish lesson that teaches a newcomer by having them _do_ something
and succeed. It holds the reader's hand and guarantees a working result. It is not a how-to guide,
which assumes the reader is already competent, and it is not reference, which lists facts.

Write one tutorial per file. See https://diataxis.fr/tutorials/.
