# Explanation

This directory holds the **understanding-oriented** documentation for this repository, one of the
four kinds of documentation in [Diátaxis](https://diataxis.fr), the framework these docs follow.
This page explains what belongs here, and the directory starts out empty.

Explanation is the reflective, "why" material: background, context, trade-offs, and the reasoning
behind decisions. It deepens understanding and can be read away from the code. A design decision
with a clear choice point belongs in `../decisions/` instead, written as an Architecture Decision
Record (ADR), which is a short document that captures one decision, the options considered, and the
consequences.

See https://diataxis.fr/explanation/.
