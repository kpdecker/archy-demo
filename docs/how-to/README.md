# How-to guides

This directory holds the **task-oriented** documentation for this repository, one of the four kinds
of documentation in [Diátaxis](https://diataxis.fr), the framework these docs follow. This page
explains what belongs here; the guides themselves are the other files in this directory.

A how-to guide gives the steps needed to accomplish one specific real-world goal, such as "How to
add a database migration". It is written for someone who already knows the basics, so it assumes
competence and stays focused on the task instead of teaching.

Write one goal per file. See https://diataxis.fr/how-to-guides/.
